CodeFormatter.ValidateFSharpCodeAsync(isSignature, source)

Full Usage: CodeFormatter.ValidateFSharpCodeAsync(isSignature, source)

Parameters:
    isSignature : bool - Determines whether the F# parser will process the source as signature file.
    source : string - F# source code

Returns: Async<ValidationResult>

Check whether an input string is valid F# by attempting to parse the code, and report what about it is not when it is not.

This replaces IsValidFSharpCodeAsync, which answered with a bare boolean. A caller that has to tell somebody why the source was refused could not reconstruct the reason from that answer, and asking a second time would parse the source a second time. Read IsValid off the result where the verdict alone is what was wanted.

isSignature : bool

Determines whether the F# parser will process the source as signature file.

source : string

F# source code

Returns: Async<ValidationResult>
